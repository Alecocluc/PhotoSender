# PhotoSender Android App PRD ## Product Overview PhotoSender is a wireless media transfer app for sending photos and videos from Android to PC over local Wi-Fi. It's built for speed, privacy, and simplicity—no accounts or cloud required. ## Target User Android users who want a quick, private way to back up or transfer media to their computer without cables or third-party cloud services. ## Core User Flows (Android) 1. **Connect:** User opens the app, sees connection status, and enters the IP address shown on their Desktop app. 2. **Browse & Select:** User navigates through local folders (Camera, Screenshots, etc.), filters by media type, and selects files for transfer. 3. **Transfer:** User initiates the upload and monitors real-time progress of parallel transfers. 4. **Manage:** User views transfer history and adjusts app settings. ## Key Features & Requirements * **Material Design 3:** Clean, modern UI with support for dynamic color. * **Connection Management:** IP address input, color-coded status indicator (Green=Connected, Yellow=Connecting, Red=Disconnected). * **Smart Gallery:** Folder-based browsing, "Select All" shortcuts, and file type filters (All, Photos, Videos). * **High-Speed Uploads:** Visual representation of up to 6 parallel file transfers. * **Deduplication & Resume:** The UI should reflect that the app remembers previous transfers and can resume interrupted ones. * **Upload History:** A simple log or summary of past activity. ## Screen List 1. **Connection Screen:** Entry point for IP and status. 2. **Media Gallery:** The primary browsing and selection interface. 3. **Active Transfer:** Real-time progress monitoring. 4. **Settings/History:** Management and overview.
